# TheRidgwells/.github

The Ridgwell Family's GitHub organisation profile. [`profile/README.md`](profile/README.md) is what shows on
[github.com/TheRidgwells](https://github.com/TheRidgwells).

## What's in here

| Path | What it is |
|---|---|
| `profile/README.md` | The organisation's profile page: every family site and repository, and the status page |
| `commit.sh` / `commit.bat` | Commit and tag a release, from the version in `VERSION.md` |
| `tests/version.sh` | Checks `VERSION.md` |

## Keeping it current

When a site or repository is added, renamed or retired, update `profile/README.md` in the same change. Public
repositories get a link; private ones are listed by name only. Ridgwell Status is always
[status.ridgwell.family](https://status.ridgwell.family).

## Versioning

This project is **pre-stable** and uses [Semantic Versioning](https://semver.org) on `0.x.y` (tags `v0.x.y`). Its
first stable release will be its first [Date Versioning](https://datevers.ing) release: the UTC release date as
`YY.MM.DD`, with `-1`, `-2`… for later releases the same day, and every release after it stays on Date Versioning.
There is no `1.0.0`. See [CHANGELOG.md](CHANGELOG.md) for what changed in each release.
